# Chess Stats — аналитика chess.com

Локальный сервер + веб-интерфейс (Bootstrap + Chart.js), который по нику или ссылке
на профиль chess.com собирает и анализирует статистику игрока через открытое API
chess.com (без ключей и авторизации).

## Что умеет

- Вставьте **ник** (`hikaru`) или **ссылку** (`https://www.chess.com/member/hikaru`) —
  username извлекается автоматически.
- Профиль: имя, титул, флаг/страна, дата регистрации, последний онлайн, подписчики, статус, лига.
- Рейтинги по контролю времени (блиц/рапид/пуля/ежедневные/960): текущий, лучший, счёт W/L/D.
- Анализ партий за выбранный период (3/6/12/24 мес или вся история):
  - общий результат и отдельно **за белых** и **за чёрных**;
  - **дебюты** (по ECO и названию) — топ по частоте, победы/поражения/ничьи, % очков;
  - разбивка по контролю времени;
  - график **рейтинга по месяцам** (белые/чёрные);
  - частые соперники.
- Всё кэшируется в локальные **JSON-файлы** (папка `data/`) — «база данных» без СУБД.

## Требования

- Доступ в интернет (для открытого API chess.com).
- Портативный Node.js — папка `runtime/` в репозиторий **не попадает**, скачай её один раз:

  1. Скачай `https://nodejs.org/dist/latest-v24.x/node-v24.21.0-win-x64.zip`
  2. Распакуй в `runtime/`, чтобы получился путь `runtime/node-v24.21.0-win-x64/node.exe`.

Либо просто запусти `start.bat` — он сам проверит наличие Node и подскажет, что скачать.

## Запуск (Windows)

Двойной клик по **`start.bat`** — сервер поднимется на `http://localhost:8000`
и браузер откроется сам.

Либо вручную:

```
runtime\node-v24.21.0-win-x64\node.exe server.js
```

Остановка — `Ctrl+C` в окне сервера. Порт можно поменять: `set PORT=9000` перед запуском.

## Структура проекта

```
chess-stats/
  server.js            # бэкенд: HTTP-сервер + прокси к API + парсер PGN + JSON-кэш
  start.bat            # запуск в один клик
  static/
    index.html         # интерфейс (Bootstrap)
    app.js             # логика фронтенда + графики (Chart.js)
    style.css
    vendor/            # bootstrap + chart.js (локально, без CDN)
  runtime/             # портативный Node.js
  data/                # JSON-база (создаётся автоматически)
    players/<nick>.json
    games/<nick>.json
```

## API

- `GET /api/health` — проверка, что сервер жив.
- `GET /api/player?input=<ник_или_ссылка>` — профиль + рейтинги (кэш 6 ч).
- `GET /api/analyze?username=<ник>&months=12[&refresh=1]` — полный анализ партий
  (кэш 24 ч; `months=all` — вся история; `refresh=1` — игнорировать кэш).

## Как это устроено

1. Из ввода регуляркой достаётся username.
2. Запрашиваются `https://api.chess.com/pub/player/{u}`, `.../stats`, `.../games/archives`.
3. Для каждого месяца скачиваются партии; из PGN каждой партии читаются заголовки
   (`Result`, `ECO`, `ECOUrl` → имя дебюта, `WhiteElo`, `BlackElo`).
4. Всё агрегируется и сохраняется в `data/games/{nick}.json`.

Запросы к chess.com идут с заголовком `User-Agent` (API без него отвечает 403) и
с паузой между архивами по месяцам (вежливость к лимитам). Для топ-игроков с сотнями
тысяч партий выбор «вся история» может занять несколько минут.

## Примечания

- Используются только штатные модули Node.js — `npm install` не требуется.
- Чтобы обновить Node, замените папку `runtime/node-v24.21.0-win-x64/` и поправьте
  путь в `start.bat`.
